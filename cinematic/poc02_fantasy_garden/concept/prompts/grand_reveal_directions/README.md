# Grand Reveal: four directions

Four deliberately different compositions of the hero frame (Frame 2), to choose a visual direction before animation.
Each file is complete and paste-ready: the world bible (00_world_bible.txt), one direction block, and the closing
block (99_closing.txt), all unchanged except the direction block. Full specs, a differences table and per-direction
checks: the "v5 · Grand Reveal directions" tab in the production doc.

| File | Direction | In one line |
| --- | --- | --- |
| frame2A_epic_valley.txt | A · Epic Valley | 150 m up on the rim, 21 mm: monumental cliffs, one three-tier fall, the pavilion a speck |
| frame2B_enchanted_paradise.txt | B · Enchanted Paradise | 1 m above the shallows, 40 mm f/2.8: backlit wisteria, crocus, glass-clear water |
| frame2C_portal_reveal.txt | C · Portal Reveal | Inside a shadowy floral passage, eye height: the valley through the gilded arch; built for the hand-held push-through |
| frame2D_petalpal_wonderland.txt | D · PetalPal Wonderland | Terrace by the great tree, 32 mm: treehouse door, slate-blue pavilion, arch, waterfall, crocus |
| midjourney_directions.txt | All four | Short Midjourney versions |

Attach ../../reference/motif_board.png as a design-motif and palette reference only. Generate 3-4 candidates per
direction with the same tool and save to ../../candidates/ as f2A_codex_01.png ... f2D_codex_04.png.
The existing prompt files in ../ are unchanged.
