## 第一部分：内测用户须知（发给用户）

### 欢迎来到 PetalPal 内测 🌸

PetalPal 把你每天的小事和心情变成一座会长大的花园，花园里住着一位小花仙 PPL。感谢你帮我们试用！这是**内测版**，
可能会有小问题，你的反馈会直接影响正式版。

### 怎么进入

1. 打开 **https://app.jastrevia.com**
2. 第一次会看到一个邮箱验证页面（Cloudflare Access）：输入你收到邀请的邮箱，填写邮件里的验证码。
3. 进入后注册 PetalPal 账号，验证邮箱，就能进入你的花园。

用手机或电脑浏览器打开就可以，目前还没有 App Store 版本。App 默认是英文。在 Settings → Report language 里选简体中文后，每周回顾、PPL 的朋友圈、签到、信物和花语卡会换成中文（重新打开 App 后生效），其他页面暂时还是英文。

如果 PetalPal 一段时间没人用（比如半夜），第一次打开可能要等一分钟左右，等待时会有花语小卡片陪你。

### 可以试试这些

- **写一个 Event**：记下今天的一件小事，选一个心情（晴朗、温柔、安静、疗愈、火焰、好奇、迷茫、平静），花园里就会长出一朵花。也可以用语音输入。**每天最多长两朵花**，删掉一朵也不会多出名额；当天再写的心情照样会保存，只是不再长花。
- **看看你的花园**：把花种到你喜欢的位置，点一朵花可以看它的花语和那天的事。小花仙 PPL 会在花园里散步、喝茶、荡秋千，点她可以让她做不同的事。
- **每日签到和信物**：在花园的日历里每天签到一次，PPL 会送你一件信物（一共 33 件，有普通、稀有和每月限定）。连续签到 7 天会得到一件稀有信物。
- **今日花语卡**：签到领完信物后，转动花环，从整副花语卡里抽一张，每天一次。抽到的卡会记在日历上。
- **Our Bond（亲密度）**：签到、写心情、和 PPL 互动、给她的朋友圈点赞都会增加亲密度，升级会解锁新的称号。在这里也能翻看你收集到的所有信物。
- **Fairy Moments（PPL 的朋友圈）**：看看 PPL 每天在花园里做了什么，可以给她点赞，还能换朋友圈的封面背景。
- **头像**：在 Me 页面点你的头像，可以从头像库里换一个。
- **每周回顾**：写满一周后，下周一起可以在树屋里的 Reflection 生成「上周回顾」。它只根据你写下的内容整理，不会替你下结论。
- **好友和拜访**：加好友后可以去对方的花园看花。好友只能看到花，看不到你写的文字。

### 你需要知道的

- **你的记录是私密的**：只有你自己能看到你写的 Event 和回顾。
- **AI 是可选的**：在 Settings 里可以随时打开或关闭。打开后，你写的 Event 文字和你提交的语音会发送给 Cloudflare Workers AI，或经 Cloudflare AI Gateway 发送给 Anthropic，用来生成心情建议、语音转写和每周回顾。处理可能在你所在国家以外进行。关闭后不会再发送新的内容，但已经发送的无法撤回。详细说明在 App 内的 AI 说明页。
- **PetalPal 不是医疗或紧急服务**。如果你或身边的人有危险，请立即联系当地紧急服务或你信任的人。
- **内测数据会保留**：内测结束后你的花园、记录和信物都会留着，正式版里继续使用。内测期间注册的账号会一直带着「Beta tester / 内测用户」标识，在 Me 页面的名字下面可以看到。
- **备份**：我们会定期备份数据库，防止服务器出问题时丢掉大家的花园；但你自己删除的记录没法单独帮你找回，删除前请想清楚。
- **删除**：你可以随时删除某条记录，或在 Settings 里删除整个账号。

### 怎么反馈

- 在 App 里：**Settings → Report a problem**，会打开一封写好格式的邮件，自动带上设备和时间，你补充一下发生了什么就行。
- 或者直接发邮件到 **contact@jastrevia.com**。
- 截图时请注意不要截到你不想分享的私人内容、邮箱或密码。
