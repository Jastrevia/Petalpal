方向见 [CONTENT_UPGRADE.md](CONTENT_UPGRADE.md)：温柔但不诗意。

## 这一稿的写法

- **一句（牌名下面那行）：** 用平常的话说这张牌讲什么。原来已经平实的不动（表里标“一句不变”，中英文共 18 处），只改带比喻或抒情的。
- **正文两句：** 第一句只说画面里有什么，用的全是现有文案里已经写到的东西，没有新增任何画面细节（我看不到原画）。
  第二句固定用“这张牌讲的是……”说它的传统含义。
- **去掉的：** 比喻、意象、抒情句，以及“也没关系 / 就好 / 本身就 / 是一种 / 值得”这类安慰式收尾（现在的中文正文里有 30 张用到，改后 0 张）。
- **不对用户说话：** 正文不出现建议、预测或对用户处境的判断，因为同一段文字也会出现在周报的花语卡里。
- **英文：** 按同一标准重写，不是逐句翻译中文。
- **9 张重牌不动**（表在最后）：等原画到了对着画改。

需要你定的两件事：

1. 正文第二句统一用“这张牌讲的是……”，69 张读下来句式是一样的。好处是清楚、像一本工具书；如果觉得太整齐，可以改成只保留冒号后面那半句。
2. 正文要不要保留第一句的画面描述。牌就在文字上方；如果按解读的标准“不描述画面”，正文可以只留第二句。
